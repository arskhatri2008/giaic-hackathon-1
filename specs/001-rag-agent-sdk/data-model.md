# Data Model: RAG-Enabled Agent

## Key Entities

### Agent
- **Description**: The OpenAI Agents SDK-based entity that orchestrates the RAG process
- **Attributes**:
  - `agent_id`: Unique identifier for the agent instance
  - `instructions`: System instructions for the agent's behavior
  - `tools`: List of available tools (including retrieval tool)
  - `model`: The underlying AI model being used (e.g., gpt-4)
- **Relationships**: Uses Retrieval Tool to access Book Content

### Retrieval Tool
- **Description**: Interface between the agent and the Qdrant-based pipeline
- **Attributes**:
  - `tool_name`: "retrieve_book_content"
  - `description`: Function that retrieves relevant book content based on query
  - `parameters`: Query string to search for in the knowledge base
- **Relationships**: Accesses Book Content from Qdrant vector database

### Book Content
- **Description**: Source material stored in the Qdrant vector database
- **Attributes**:
  - `content_id`: Unique identifier for the content chunk
  - `text`: The actual text content retrieved
  - `metadata`: Additional information about the source (book title, page, section, etc.)
  - `embedding`: Vector representation for similarity search
- **Relationships**: Referenced by Retrieval Tool responses

### Agent Response
- **Description**: Output generated by the agent that contains answers grounded in retrieved book content
- **Attributes**:
  - `response_id`: Unique identifier for the response
  - `content`: The text response to the user query
  - `source_chunks`: References to the book content chunks used to generate the response
  - `confidence`: Measure of how well the response is grounded in the retrieved content
- **Relationships**: Generated from Agent using Book Content via Retrieval Tool

## Data Flow

1. User provides a query to the Agent
2. Agent invokes the Retrieval Tool with the query
3. Retrieval Tool searches Book Content in Qdrant database
4. Retrieved Book Content is provided back to the Agent
5. Agent generates an Agent Response based on the retrieved content
6. Agent Response is returned to the user

## Validation Rules

- Agent responses must reference specific Book Content chunks
- If no relevant Book Content is found, the Agent Response must indicate insufficient information
- All Agent Responses must be verifiable against the provided Book Content
