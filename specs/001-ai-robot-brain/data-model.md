## Entity Relationships

### Core Entities

1. **NVIDIA Isaac Sim**
   - Type: Simulation Platform
   - Properties: Physics engine, rendering capabilities, sensor simulation
   - Relationships: Generates synthetic data → Feeds Isaac ROS perception

2. **Isaac ROS**
   - Type: Robotics Framework
   - Properties: Hardware acceleration, perception pipelines, sensor fusion
   - Relationships: Processes data from Isaac Sim → Enables VSLAM

3. **Visual SLAM**
   - Type: Algorithmic Process
   - Properties: Localization, mapping, real-time constraints
   - Relationships: Implemented in Isaac ROS → Used by Nav2 navigation

4. **Nav2 Navigation Stack**
   - Type: Navigation Framework
   - Properties: Path planning, obstacle avoidance, behavior trees
   - Relationships: Uses VSLAM data → Connects to AI planning

5. **Synthetic Data**
   - Type: Training Material
   - Properties: Photorealistic, domain-adaptable, diverse scenarios
   - Relationships: Generated by Isaac Sim → Used to train perception models
