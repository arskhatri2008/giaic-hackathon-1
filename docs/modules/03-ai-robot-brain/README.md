# Module 3: AI-Robot Brain (NVIDIA Isaac™)

This module covers NVIDIA Isaac as the AI brain for humanoid robots, focusing on perception, navigation, and training through accelerated simulation and robotics frameworks.

## Chapters

1. [**Chapter 1**: NVIDIA Isaac Sim and Synthetic Data](/docs/modules/ai-robot-brain/chapter-1-isaac-sim)
   - Photorealistic simulation in Physical AI
   - Synthetic data generation for perception models
   - Training AI systems using simulated humanoids
   - Bridging simulation data to real-world robots

2. [**Chapter 2**: Isaac ROS for Perception and VSLAM](/docs/modules/ai-robot-brain/chapter-2-isaac-ros-perception)
   - Hardware-accelerated perception pipelines
   - Visual SLAM concepts for humanoid robots
   - Sensor fusion with cameras and IMUs
   - Real-time constraints in embodied AI systems

3. [**Chapter 3**: Navigation and Path Planning with Nav2](/docs/modules/ai-robot-brain/chapter-3-nav2-navigation)
   - Fundamentals of robotic navigation stacks
   - Path planning for bipedal humanoids
   - Obstacle avoidance and environment awareness
   - Integration of navigation with higher-level AI planning

## Prerequisites

- Module 1: ROS 2 as robotic nervous system
- Module 2: Digital twin simulation

## Learning Objectives

After completing this module, you will be able to:
- Explain how NVIDIA Isaac enables perception, mapping, and navigation for humanoid robots
- Understand the perception-to-navigation flow in Isaac-based systems
- Describe how humanoid robots localize and move in their environment
- Apply knowledge of Isaac Sim, Isaac ROS, and Nav2 to practical scenarios

## Personalized Learning Paths

This module supports different learning paths based on your background:

- **AI Engineers**: Focus on perception and training workflows in Isaac Sim and Isaac ROS
- **Robotics Developers**: Emphasize navigation and path planning with Nav2
- **Beginners**: Follow the complete sequence from simulation to navigation
- **Experts**: Skip to specific sections using the detailed table of contents
