# Module 2: The Digital Twin (Gazebo & Unity)

## Introduction

Welcome to Module 2 of the Physical AI & Humanoid Robotics course! In this module, we'll explore the concept of digital twins for humanoid robots using simulation environments. This enables safe, repeatable, and physics-accurate testing of embodied AI systems before real-world deployment.

### Building on Module 1

In Module 1, you learned about ROS 2 as the robotic nervous system, covering communication primitives, nodes, topics, services, and robot structure with URDF. Now, we'll use that foundation to create virtual environments where you can safely test your robotic concepts.

### What You'll Learn

This module covers three key areas:

1. **Physics-Based Simulation with Gazebo**: Learn how to create realistic physics simulations of humanoid robots, including gravity, collisions, friction, and joint constraints.

2. **High-Fidelity Environments with Unity**: Explore how visual realism matters in Physical AI and how Unity can serve as a digital world for human-robot interaction.

3. **Virtual Sensor Integration**: Understand why robots need simulated sensors and how LiDAR, cameras, and IMUs work in simulation environments.

### Prerequisites

Before starting this module, you should have:
- Basic understanding of ROS 2 concepts from Module 1
- Familiarity with robot concepts (links, joints, URDF)
- Understanding of basic physics concepts (gravity, collisions, friction)

### Learning Outcomes

After completing this module, you will be able to:
- Explain the role and value of digital twins in robotics development
- Distinguish between Gazebo and Unity roles in robotics simulation
- Understand how virtual sensors are simulated and used
- Implement physics-based simulations for humanoid robots
- Create high-fidelity environments for perception system training
- Connect simulation outputs to ROS 2-based AI systems
