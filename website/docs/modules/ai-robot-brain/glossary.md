# Glossary - AI-Robot Brain (NVIDIA Isaac™)

This glossary defines key technical terms used throughout Module 3: The AI-Robot Brain (NVIDIA Isaac™).

## A

**A* (A-star)**: A graph traversal and path search algorithm that is widely used in many fields of computer science due to its completeness, optimality, and optimal efficiency.

## D

**Domain Adaptation**: Techniques that help models trained on synthetic data perform well on real data by reducing the domain gap between simulation and reality.

**Domain Randomization**: A technique involving varying visual and physical parameters during training to make models more robust to domain shift between simulation and reality.

## E

**Extended Kalman Filter (EKF)**: A nonlinear state estimator that linearizes the system around the current estimate to handle nonlinear systems in sensor fusion applications.

## G

**Global Planner**: A path planning component that computes a high-level path from start to goal using a static map of the environment and considering known obstacles.

## I

**Isaac ROS**: A collection of hardware-accelerated perception and navigation packages designed to run on NVIDIA robotics platforms, optimized for NVIDIA hardware.

**Isaac Sim**: A photorealistic simulation application and application framework based on NVIDIA Omniverse for developing, testing, and validating AI-based robotics applications.

## L

**Local Planner**: A path planning component that executes the global path while avoiding dynamic obstacles, operating in a local window around the robot with real-time sensor data.

**Loop Closure**: A process in SLAM that detects revisited locations to correct drift in the estimated map and trajectory.

## N

**Navigation2 (Nav2)**: The next-generation navigation framework for ROS 2, designed to provide reliable path planning and navigation capabilities for mobile robots.

**NITROS (NVIDIA Isaac Transport for ROS)**: An optimized data transport system for ROS that enables efficient communication between nodes with zero-copy transfers.

## S

**Simultaneous Localization and Mapping (SLAM)**: A computational problem of constructing or updating a map of an unknown environment while simultaneously keeping track of an agent's location within it.

**Sensor Fusion**: The process of combining data from multiple sensors to create a more accurate and robust understanding of the environment.

**Synthetic Data**: Artificially generated data that mimics real-world sensor inputs for training AI models without physical data collection.

## V

**Visual SLAM (VSLAM)**: A specific type of SLAM that uses camera data to build maps of unknown environments while simultaneously localizing the camera within those maps.

**Voxel Layer**: A 3D obstacle information layer in Nav2 costmaps that provides height and depth information for more complex environment representation.
