# Module 1: The Robotic Nervous System (ROS 2)

Welcome to Module 1: The Robotic Nervous System (ROS 2). This module introduces you to ROS 2 as the foundational nervous system for humanoid robots, enabling communication, control, and structural description of embodied AI systems.

## What You'll Learn

In this module, you'll gain a comprehensive understanding of:

- **ROS 2 Fundamentals**: What ROS 2 is and why it exists, and how it differs from traditional software architectures
- **Communication Primitives**: How nodes, topics, services, and actions work together to create complex robot behaviors
- **Robot Modeling**: Using URDF (Unified Robot Description Format) to model humanoid robots and their structure

## Target Audience

This module is designed for:
- AI engineers and software developers transitioning into robotics
- Learners with Python and basic AI background
- Anyone following the Physical AI & Humanoid Robotics course

## Module Structure

This module is divided into three chapters:

1. [Chapter 1: Introduction to ROS 2 as a Robotic Nervous System](./chapter-1-introduction-to-ros2) - Understanding the basics of ROS 2 architecture
2. [Chapter 2: ROS 2 Communication Primitives](./chapter-2-ros2-communication-primitives) - Learning about nodes, topics, services, and actions
3. [Chapter 3: Humanoid Robot Structure with URDF](./chapter-3-urdf-humanoid-robot-structure) - Modeling humanoid robots with URDF

## Prerequisites

Before starting this module, you should have:
- Basic knowledge of Python programming
- Familiarity with software architecture concepts
- Interest in robotics and AI integration
