# Interactive UI Components

This directory contains custom interactive components for the Docusaurus documentation site. These components enhance the user experience with improved navigation, interactive content, and responsive design.

## Components

### Navigation Components
- `InteractiveSidebar`: Enhanced sidebar navigation with collapsible sections
- `ResponsiveNavbar`: Improved navigation bar with mobile-friendly menu
- `Breadcrumb`: Breadcrumb navigation for documentation hierarchy

### Content Components
- `ExpandableSection`: Collapsible content sections for detailed information
- `InteractiveCodeBlock`: Code examples with copy and execution capabilities
- `KnowledgeCheck`: Interactive quizzes and knowledge validation
- `TabbedInterface`: Tabbed interface for multi-language examples

### Utility Components
- `ThemeSwitcher`: Theme switching functionality for light/dark modes

## Usage

These components are integrated into the Docusaurus site through MDX files and custom page layouts. Each component follows accessibility best practices and responsive design principles.

## Architecture

Components are built with React and TypeScript, following Docusaurus best practices for custom component development. They use CSS modules for styling to avoid conflicts with existing Docusaurus styles.
